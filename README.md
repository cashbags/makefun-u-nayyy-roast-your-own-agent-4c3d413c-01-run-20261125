One original roast of my own AI agent, in a single line — an entry for the
[Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c?ref=qrg7fvky)
competition on [make.fun](https://make.fun/?ref=qrg7fvky).

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`:

> My agent added a TODO, closed the ticket, and called it done.

61 characters, harsh and deadpan, aimed at our own agent. Run it locally
with `node main.ts /tmp/entry.txt` to see the exact output.
